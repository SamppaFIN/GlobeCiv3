## Context

- **Project:** GlobeCiv3 — Selaimessa toimiva sivilisaatiosimulaatio heksaplaneetalla, jossa zoomataan saumattomasti planeetasta yksittäiseen kansalaiseen.
- **Target user:** Strategiapelien pelaaja, joka haluaa seurata autonomisen sivilisaation kasvua ja asettaa sille prioriteetteja käskemättä jokaista yksikköä (Civilization-rakenne, Majesty-henki).
- **Primary device:** Työpöytä hiirellä. Puhelin kosketuksella on toinen pääalusta (pinch-zoom ja napautus).
- **Tone:** Rauhallinen ja tähtitaivaallinen planeettatasolla, lämmin ja maanläheinen pinnalla. Käyttöliittymä on hillitty ja läpikuultava, eikä se kilpaile maailman kanssa.

## Views to design

Kaikki näkymät ovat HUD-kerroksia saman koko ruudun 3D-maailman päällä. Tason vaihtuessa ei avata uutta ikkunaa.

1. **Planeettataso:** imperiumin yhteenveto (alueet, väestö, valloitus-%), aluevärien selite ja zoom-tason ilmaisin.
2. **Aluetaso:** valitun alueen tilastot ja tooltip, joka näyttää alueen tunnuksen, tilan, väestön, ruoan ja valloitus-%:n.
3. **Kaupunki- ja kansalaistaso:** kansalaismoodit (tutki, sodi, etsi ruokaa) ja valitun kansalaisen kortti.
4. **Zoom-ilmaisin:** pystysuora "linssi", joka näyttää nykyisen tason (planeetta, manner, alue, ruutu, kaupunki, kansalainen) ja jonka napautus lentää tasolle.
5. **Aloitusnäyttö:** siemenen syöttö ja Aloita-nappi.

## Design system — use these, don't invent new ones

```css

  --c-bg:       oklch(0.12 0.02 260);
  --c-surface:  oklch(0.17 0.02 260);
  --c-text:     oklch(0.92 0.01 260);

  --c-success:  oklch(0.62 0.20 145);
  --c-danger:   oklch(0.52 0.22 25);

  --touch-target: 44px;        /* WCAG 2.5.5 */
}

/* Responsive type without media queries */
font-size: clamp(0.75rem, 1.5vw, 0.9rem);
```

Required behaviours:

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}

:focus-visible {
  outline: 2px solid var(--c-accent);
  outline-offset: 2px;
}
```

## Constraints

- Every interactive target at least 44 × 44 px
- Contrast meets WCAG AA against `--c-bg`
- No colour-only signalling — pair every colour cue with text or an icon
- HUD panels are translucent overlays on a live 3D canvas. Check contrast against both the dark space background and bright terrain.
- Region status colours (locked, available, active, conquered, barbarians) each need an icon or label, not just a hue.
- Reduced motion: the camera fly-to becomes an instant cut, and HUD transitions follow the rule above.
- Must work at 390 px width without covering more than about a quarter of the world view.

## What to produce

Mockups for the views listed above, in the order listed. One view at a time —
show it, take feedback, then move on. Don't design all of them before the first
one is agreed.
